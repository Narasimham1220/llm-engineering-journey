# LLM Engineering Journey

My notes and practice while learning to become an LLM Engineer.

I'm following the [LLM Engineering course by Ed Donner](https://github.com/ed-donner/llm_engineering).

## What's inside

- `notes/`: my notes, in English
- `week1/` to `week8/`: my code and exercises for each week

## Progress

- [x] Week 1: Talk to an AI from code

- [ ] Week 5: RAG (AI answers from my documents)
- [ ] Week 6: Fine-tuning a paid model
- [ ] Week 7: Fine-tuning a free model (LoRA)
- [ ] Week 8: Agents

## How to run

1. Install [uv](https://docs.astral.sh/uv/)
2. Run `uv sync`
3. Make a `.env` file and add your API key
4. Open a notebook and run the cells from top to bottom
